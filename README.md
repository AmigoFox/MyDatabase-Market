# MyDatabaseMarket

## 📌 О проекте

**MyDatabaseMarket** — это кроссплатформенное приложение для конфигурирования, расчёта стоимости и управления заказами облачных баз данных.

Проект реализует полный цикл взаимодействия пользователя с системой:

* создание конфигурации базы данных
* расчёт стоимости на основе параметров
* оформление заказа
* управление заказами
* проведение оплаты
* просмотр истории платежей

Приложение построено с использованием современной архитектуры и разделения ответственности между клиентом и сервером.

---

## 🧠 Зачем этот проект

Проект разрабатывался как **практическая реализация архитектуры клиент-серверного приложения**, с акцентом на:

* MVVM (на клиенте)
* REST API (на сервере)
* работу с бизнес-логикой (расчёт цен, статусы заказов)
* UX (понятные состояния, дедлайны, статусы)

Основная цель — не просто “сделать CRUD”, а построить систему, приближенную к реальному продукту.

## ⚙️ Архитектура

### 📱 Клиент (MAUI)

Структура:

```
CrossApp
├── Models
├── Services
│   ├── Api (HttpClient + AuthHandler)
│   ├── AuthTokenStore
├── ViewModels
├── Pages (XAML)
└── MauiProgram (DI)
```

Используемые принципы:

* MVVM (View ↔ ViewModel)
* Dependency Injection
* DTO для взаимодействия с API
* Shell Navigation

---

### 🌐 Backend (ASP.NET Core)

* REST API (`/api/v1/...`)
* Entity Framework Core
* PostgreSQL

Основные сущности:

* **Order** — заказ пользователя
* **OrderItem** — конфигурация базы данных
* **Payment** — платеж

---

## 💳 Бизнес-логика

### Заказы

* создаются на основе конфигурации БД
* автоматически рассчитывается стоимость
* имеют статусы:

  * `created`
  * `paid`
  * `expired`

### Платежи

* создаются только для своих заказов
* сумма берётся с сервера (защита от подмены)
* защита от повторной оплаты
* нормализация методов оплаты

---

## 🧩 Основной функционал

### 📦 Конфигуратор БД

* выбор типа БД
* настройка:

  * размер (GB)
  * IOPS
  * тип хранилища
  * масштабируемость
  * дополнительные параметры (backup, sharding и др.)
* расчёт цены в реальном времени

---

### 🧾 Заказы

* список заказов
* отображение:

  * названия заказа
  * суммы
  * дедлайна оплаты
  * статуса (цветом)
* удаление
* переход к деталям

---

### 🔍 Детали заказа

* полная информация о конфигурации
* редактирование
* удаление
* оплата

---

### 💳 Оплата

* выбор метода оплаты
* проверка дедлайна
* защита от повторной оплаты
* обновление статуса заказа

---

### 📊 История платежей

* список всех платежей пользователя
* сортировка по дате
* отображение:

  * суммы
  * метода
  * статуса
  * даты

---

## 🎯 UX решения

* статус заказа отображается цветом:

  * 🟢 оплачено
  * 🟡 ожидает оплаты
  * 🔴 просрочено
* дедлайн оплаты показывается в списке заказов
* кнопка оплаты доступна только при необходимости
* после оплаты UI обновляется без лишней навигации
* система уведомлений (ValidationState)

---

## 🔐 Безопасность

* авторизация через JWT
* проверка владельца заказа
* сумма платежа рассчитывается на сервере
* защита от двойной оплаты
